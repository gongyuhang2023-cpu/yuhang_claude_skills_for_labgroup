# 科研汇报内容层：骨架、页面单元、证据呈现

> 适用：组会 progress report、journal club 及其他内部科研汇报。引擎管版式美学，本页管每页讲什么、证据怎么摆。讲稿规则见 `talk-notes.md`，排版规范见 `scientific-norms.md`。
> 原则：页面给人看数据和重点；解释交给讲稿，细节交给备用页。

## 0 开工前

1. 盘点能用的真实材料：结果图文件、原始数据、论文 PDF、已有 deck。页面只建立在找得到出处的材料上。
2. 建事实表：deck 里出现的每个数字，在 `facts.md` 记一行（编号、数值、口径或单位、来源文件、日期）。走引擎时放工程目录；只写讲稿或只做规划时，放在讲稿或规划文件旁边。素材是别人整理好交来的，来源写"用户提供"和收到的日期。数字取自项目当前的权威记录（pathway、STATUS、pm），不从旧 deck 或记忆沿用。缺的写 `[MISSING: 缺什么]`，不估计，不举例代替。
3. 定汇报类型、时长、语言版本。

## 1 骨架

### 1.1 Progress report

开场一页：本次要讨论的问题，以及想要组里给哪类意见（设计、解读还是下一步）。

多个项目各自交代背景和问题，不包装成一个大课题。每个项目：

| 段 | 内容 |
|---|---|
| 背景 | 现状 → 依据 → 目标。陈述句标题，不用设问；只铺垫到能看懂本项目的工作 |
| 问题 | 编号列出本项目要回答的 2–3 个问题 |
| 设计与方法 | 一张总体研究设计图，标出已完成、进行中、计划和本次新增的位置；讲清有哪些备选方法、为什么选这个、预期产出什么 |
| 工作 ①②③ | 每项：做了什么 → 发现什么 → 下一步。已有结果和未完成的决定分开放 |
| 小结 | 已完成的工作 / 这些结果说明了什么 |
| 下一步 | 编号，和前面的局限一一对应；卡点和需要组里帮忙的事单列 |

末页是小结和要组里回答的问题，讨论时停在这页；标志可以放在这页。备用页放在末页之后。

组会不是展示。阴性结果、失败、小规模试验和改变路线的证据照讲，写清边界。不用工作量、资源规模、计算分数代替科学结论。

### 1.2 Journal club

| 段 | 内容 |
|---|---|
| 题名页 | 出版页或 PDF 首页的真实截图：期刊、题名、作者、摘要 |
| 作者背景 | 课题组和相关前期工作，一页 |
| 概念 | 只讲进入第一个问题前必须懂的；其余在第一次用到的那页再讲 |
| 数据与方法 | 点名数据来源；用对照或流程图说清和常规做法的区别 |
| 问题 → 证据 → 答案 | 每个科学问题先单独提出，再用作者原图逐步推进，最后给答案。每页分清"作者的结论"和"我们的读法"；证据边界写在对应那页 |
| 启发 | 作者做了哪些具体的分析选择让结果成立。标明是我们的阅读提炼，不猜动机，不泛泛鼓励 |
| 讨论（可选） | 1–2 个会改变大家对论文判断的问题 |

复述论文结论时不扩大范围：物种、人群、条件、时态都照原文。

## 2 页面单元

三件事都定下来才建页：本页回答什么问题、用哪份真实证据、证据允许的最窄结论。写不出来就改结论或删页。再问两句：听众离开这页要记住什么（规模、关系还是比较方向）——主视觉就给它；删掉这页，哪个判断会失去依据——答不上来就合并或移进备用页。

| 部件 | 规则 |
|---|---|
| 标题 | progress report 结果页用含谓语的完整句写发现，阴性结果也直说；背景页用陈述句；journal club 推进页可以用问题做标题，页面上必须有答案句。最多 12 个英文词、两行。同一结果跨多页时标题不变，用副标题区分 |
| 副标题 | 可选，最多 8 个英文词、一行，只补标题和图里缺的范围 |
| 证据 | 一页一个主证据：真实数据图或作者原图。主图是全页面积最大的元素；旁边有侧栏时，图宽至少占版心宽的一半，没有侧栏时按 §3 表里的常用占比。这条只管结果页 |
| 侧栏 | 可选，最多 2 块，每块连小标题最多 12 个英文词 |
| 图上文字 | 图上注释、数据卡、图注合计最多 24 个英文词 |
| 结论条 | 只在标题没说完时放：一个决定（如暂停），或一条会改变解读的限定。最多 12 个英文词、一行。和标题意思重复就不放，版面还给图 |
| 页脚 | 只放小东西：参考文字、页码、实验室标志，一行（样式见 §4）。借来的图写作者、年份、图号，加了标注的注明"标注为汇报人所加"；示意图写"示意"。完整引文、doi、方法细节、完整记录、缩写表放备用页；n、单位、分母写在图上 |
| 页码、章节标记 | 每页都有 |

整页屏上文字最多 70 个英文词，数字、缩写、可见的标识符都算；自动生成的坐标刻度、页码、章节标记、标志不算。会改变解读的限定贴着证据写，同一条限定屏上只出现一次。

页面上不写：编排旁白、操作历史、重复的导语、内部编号（DEC-、ASSET-、项目代号）、AI 厂商和模型版本。

## 3 证据呈现

- **自己的图**：用颜色突出承载结论的那部分数据，其余用灰；样本小时画出每个数据点；n、单位、统计口径写在图上。给幻灯片单独出图，不直接用论文排版尺寸的图：按最终放置尺寸，图里的字不小于 18 pt，关键标签 20 pt。图保持白底，不加底色面板；色块只给文字用。
- **论文原图**：从 PDF 矢量裁切到所讲的 1–2 个 panel，放大后使用，保留坐标轴、误差线、n 和显著性标记，锁定宽高比；不重绘、不改色、不涂抹。原图里要读的字放大后仍小于 18 pt 的，在图旁用 18 pt 以上的字写出来。用 1–2 个圈、框或箭头指出要读的地方，标记放单独一层，不压文字和数据点。
- **复杂图**：可以分 2–3 步出现（先坐标轴，再数据，再焦点），用复制页或引擎的分步实现。动态只为当前焦点服务，不做逐条飞入。
- **对比表**：只在听众要读精确值时用；同一列同一口径，让差距自己显现；格子里不写旁白；区分零、缺失和未报告；定义放表外。表格字号同样不低于 18 pt，放不下就拆表或改成图。
- **流程图**：画真实组分；工具步写"输入 → 工具 → 输出"，判断步写"要回答什么 → 怎么推理 → 定什么"；标出已完成、进行中、计划。节点只写名称，计数和细节放讲稿或备用页；节点多到字号保不住就拆页。
- **数据库或数据结构页**：关系图加一条真实记录，记录只放能支撑本页主张的字段。规模本身是要点时（如数据库建成），规模数字放大成主视觉之一，不小于 24 pt。
- **示意图**：概念和方法可以自绘或用素材，标明是示意；只画材料支持的那一层关系。只知道"多对多"这类组级关系时，用分组、括号或组级标签表达，不画连线。结果不能用示意图或 AI 生成图代替。
- **阴性结果**：单独成页，规格和阳性结果页相同，每条信息在屏上只出现一次：
  - 标题写实际比较得到的结果；不显著不写成"没有效应"；
  - 图上标组名、分析单位和 n；
  - 一个效应量和它的区间，作为能读清的结果块；
  - 一句贴着图的话，交代类型（有效阴性 / 无法判断 / 技术失败）和缺的对照或检出限制——这就是这一页的那次限定；
  - 结论条写后果：暂缓、重定向或否掉；
  - 判据细节、敏感性分析、最接近阈值的信号放备用页，讲稿里可以提。
- **改道**：去向是重定向或否掉时单独一页，写原计划、推翻它的那条观察、新计划；暂缓写进阴性结果页的结论条。
- **数字**：页面只留支撑本页主张的数字；作为主证据的数字不小于 24 pt；效应量和它的区间算一个数，没有区间时写明是没算还是给不出（例如样本太少，95% 精确区间不可达），不留空也不编。其余数字进讲稿或备用页。
- **强调**：每页最多 1–2 处。整齐和留白不等于重点已经突出。

### 连线和线条

- 每条线都要有含义：两端接在真实节点的边缘或明确的锚点上，能说出它连的是哪两样东西、依据是什么。不画装饰线，不画两端悬空的线。流程图节点不画半截边框，例如箭头两端的短竖线。节点没有框时以文字边缘为锚点，箭头端点离文字 0.10–0.25 英寸就算接上。
- 流程用直线或直角折线。两列之间的关系图可以用平滑的单段曲线。同一张图里不混用。
- 只有材料支持方向或因果时才加箭头。
- 线宽三档：网格、边框、分隔线 0.5–0.75 pt 浅灰；普通关系线 1.25–1.5 pt 中灰；主路径 2–2.5 pt 深色或一个强调色。
- 一张解释图最多 6 条有含义的连线，默认不交叉，线不穿过文字和无关节点。超出就重排或拆图；只画了部分关系时注明范围。
- 分区按这个顺序选：先用留白；留白分不清时用模块；最后才用分隔线。
- 模块是浅底色块，只给文字用，不放在图后面：整套只用一种底色（主色蓝在白底上约 6–8%，如 #EDF3F9），无描边、无阴影、直角；外沿对齐版心，里面的文字统一缩进（横 0.20 英寸，纵 0.10–0.15）。
- 用不用模块、用在哪，按页面灵活选。结论条要和正文分开时，做成整条色块。侧栏是一组要连起来读的关键数字，而且竖向放得下内边距、组间距不会被压到 0.25 英寸以下时，可以做成卡片；否则只用留白。一页最多两块模块。
- 两条分隔线不相邻：两条线之间只隔一行字或更近，就算相邻。页面已有页脚线时，正文区一般不再放横线；图和侧栏之间默认只靠留白分开。渐变淡出只用于最底部的页脚分隔线。

常见数据图的版面占比（参考）：

| 数据 | 常用图 | 图占版面 |
|---|---|---|
| alpha 多样性 | 箱线图、小提琴图 | 约 50% |
| beta 多样性 | PCoA、NMDS | 约 60% |
| 物种组成 | 堆叠柱状图 | 约 55% |
| 差异物种 | 火山图、森林图 | 约 60% |
| 功能注释 | 气泡图、柱状图 | 约 50% |
| 网络 | 宽幅网络图 | 约 70% |
| 热图 | 全宽热图 | 约 80% |

## 4 实验室版式基线

在引擎 Stage 2 作为用户指定的风格传入：

- 近白底，整套色调连续，不用大面积深色章节页。
- 主色蓝、强调色琥珀、灰；颜色只用来突出，其余用灰。两个项目时各用一个识别色，只用在章节标签和标题色带：第一个项目用主色蓝，第二个默认用暖橙（如 #C2690D）。图里突出数据的颜色和识别色分开，撞色时数据编码优先，图内改用别的颜色。
- 字号下限，按 13.33 英寸宽的 16:9 页面、最终放置尺寸计：
  - 标题 32 pt；
  - 正文、侧栏、结论条、作为主证据的数字 24 pt；侧栏里数字上方的小标签可以 18–20 pt 中灰，主数字 44–48 pt，靠大小对比分层；
  - 图内标签（轴名、刻度、图例、节点名、n、数据标注）18 pt；
  - 页脚的参考文字和页码 12 pt（页脚只给需要的人查，讲的时候不读）。

  放不下就删字、放大局部或拆页，不用自动缩字。这几个数是起始门槛，有条件时在实际会场最后一排做 5 秒试读校准。
- 字号层级不超过 5 级，跨页一致；结论条、页脚、页码位置固定。

### 间距与节奏

靠字号、行距、元素之间的距离让页面不拥挤、有呼吸，不靠删元素或改架构。间距分四级，从大到小。页面显得挤，通常是因为区块之间的距离不比组与组之间大。页面已经装满时不加空白，而是重新分配：收紧组与组之间，放大区块之间。下列是起始值（单位英寸，页面 13.33 × 7.5）：

1. **页边距**：左右各 0.67（页宽的 5%）；眉题顶边离上沿 0.50。
2. **区块之间**：标题到内容 ≥ 0.55（内容装满正文区时就取 0.55，不满时按下面「排布与对齐」居中）；图和侧栏之间约 0.80，只靠留白；内容到结论条 ≥ 0.25；最后一个内容到页脚线 ≥ 0.20。
3. **组与组之间** 0.30–0.35，至少是组内的 3 倍。侧栏里 {标签、主数字、单位}、{区间}、{结论} 各是一组；流程图每行 {主标签、副标签} 是一组；流程图到图例 0.15–0.20。
4. **组内** 0.04–0.10；标题组（眉题和标题）内部 0.12–0.18。

区块之间的每一处，至少是本页组间距最大值的 1.5 倍；有色块或页脚线隔开的那一处除外。

- 行距：标题 1.1 倍；多行正文 1.25 倍。
- 用到分隔线时，线离上下文字各 ≥ 0.12，量看得见的字形，不量文本框；确需在图和侧栏之间放竖线时，线两侧各留 ≥ 0.40。
- 对齐：眉题、标题、页脚、进度条、撑满版心宽的内容块和模块，都贴版心；按「排布与对齐」居中放的内容块除外。改边距后要逐个核对，包括图例、页脚、进度条。
- 腾空间的顺序：先把组间距收到 0.30；再按新尺寸重新出图，图内字号不变；仍不够就按字号那条删字或拆页，不缩字。

### 排布与对齐

- 眉题、标题、页脚、进度条的位置每页固定，不随内容移动。
- 内容不多时居中，不堆在左上角。看标题下方正文区里的内容块：左右撑满（约占版心宽 85% 以上）就上下居中；上下撑满就左右居中；两个方向都不满就两个方向都居中。居中的是整组内容；组里并排的几栏顶端对齐，各栏的小标题在同一高度。侧栏文字比旁边的图短时，相对图的高度上下居中。
- 多行的正文句子两端对齐，最后一行左对齐。标题、眉题、单行文字、图内标签、流程图节点名、数字、页脚不两端对齐。两端对齐会拉开词距：哪一行拉开后的词距超过正常词距约 1.5 倍，就先在 ±10% 内调栏宽（行数不变），同页同类的段落用同一栏宽；还超过就这一段保持左对齐，并在交付时指出来。
- 封面的满版底图不受版心约束，封面上的文字和标志仍按版心放。

### 页脚

- 页脚是页面底部收尾、留出呼吸的地方，只放参考文字、页码、实验室标志这类小东西。
- 页脚区（从页脚分隔线到页面底边）高 ≤ 0.55；最下方留 0.25–0.30。页脚的文字、标志、页码、分隔线左右与版心对齐。
- 参考文字和页码 12 pt 中灰，一行；标志高约 0.22–0.25；三者在同一行垂直居中对齐。
- 页脚上方的分隔线是从左侧实色到右侧完全透明的渐变淡出线，0.75 pt。整页只有这一条用渐变。
- 每页有章节进度条，高亮当前段。
- 学校、实验室标志：放哪些、哪几页放、封面怎么放，按个人习惯区（`references/*.local.md`）或课题组的规定；都没有就只在页脚放一个实验室标志。说"首尾页"时，尾页指讲完的最后一页（总结或讨论页），不是备用页。标志素材自备，不随本 skill 分发。
- 有封面素材时，规划阶段问一次用不用。封面由底图加几张小图组成时，在 PPT 里分层放：底图单独一张，每张小图各是一个独立的图片对象，起好认的名字，让人能在 PowerPoint 里右键"更改图片"自己换；不用合成好的整张图。小图里放什么先问用户。

## 5 改版纪律

- 在用户认可的版本上局部修改：先列逐页、逐对象的修改清单，清单外不动。
- 新版本另存，不覆盖旧版。
- 验收先看每页目的、实际图件和原有内容是否保留，再看渲染和文件完整性。

## 导出前检查（内容层）

这份清单在导出前跑；规划阶段的 `[MISSING]` 和还没画的图记为待办。字号、字数、连线按最终渲染检查。不适用的项写 N/A 和一句理由，不为了勾上而补分析。

可判定，不通过就不导出：
- [ ] 每个结果页都有工程目录里真实存在的图文件；借来的图有来源短引
- [ ] 页面上的每个数字都能在 `facts.md` 找到同值条目；没有残留的 `[MISSING]`
- [ ] progress report 结果页标题是含谓语的完整句；journal club 的问题页有答案句
- [ ] 字号不低于 §4 的下限，含嵌入图里的字；没有自动缩字、溢出、重叠
- [ ] 整页屏上文字不超过 70 个英文词，各区不超上限；页脚一行
- [ ] §4 间距与节奏、排布与对齐、页脚各项达标（按原生 PPTX 的对象位置量）；该贴版心的贴版心；两条分隔线不相邻；只有页脚分隔线是渐变
- [ ] 图是白底，色块只用在文字上；内容少的页按居中规则放；多行正文两端对齐，标题不两端对齐
- [ ] 带空位的封面是分层的：底图和每张空位图都是独立对象，不是一整张合成图
