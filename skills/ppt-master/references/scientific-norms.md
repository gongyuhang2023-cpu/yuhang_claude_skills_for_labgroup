# 科研 PPT 文字规范（🟢 生成全程必须遵守）

> 这些是 ppt-master 引擎（通用工具）**不会做**、而审稿人会挑的硬规则。萃取自 meeting-ppt-vba。

## 1. 斜体规则

### 必须斜体
| 类型 | 示例 |
|------|------|
| 细菌属种名 | *E. coli*, *S. aureus*, *Escherichia coli* |
| 基因名 | *lacZ*, *VEGFA*, *bla*OXA-23 |
| 拉丁术语 | *in vitro*, *in vivo*, *in situ*, *et al.* |
| 统计量 | *P* 值、样本量 *n* |

### 不斜体（正体）
| 类型 | 示例 |
|------|------|
| 蛋白名 | LacZ, VEGFA, OXA-23 |
| 噬菌体/病毒通俗名 | T4, T7, λ phage, SARS-CoV-2 |
| 细菌复数/泛指 | staphylococci, salmonellae |

### 基因命名大小写（按物种）
| 物种 | 基因(斜体) | 蛋白(正体) |
|------|-----------|-----------|
| 人类 | *BRCA1*(全大写) | BRCA1 |
| 小鼠 | *Brca1*(首字母大写) | BRCA1 |
| 细菌 | *lacZ*(三小写+末大写) | LacZ |

## 2. 数字与单位
| 规则 | 正确 | 错误 |
|------|------|------|
| 数字单位间空格 | 10 μL | 10μL |
| 温度 | 37 °C | 37°C / 37度 |
| 科学计数法用 × | 1.5 × 10⁸ | 1.5*10^8 |
| 倍数 | 2-fold, 10× | 2 fold, 10x |
| 微升/毫升 | μL, mL | ul, ml |
| 滴度/碱基 | PFU/mL, 300 bp, 1.5 Mbp | — |
| 百分比 | 95% | 95 % |

## 3. 统计规范（审稿硬指标）
| 项 | 要求 |
|----|------|
| P 值 | 报**精确值** *P* = 0.032，不写 P < 0.05 |
| 效应量 | 报效应量 + 95% CI，不只报 P |
| 多重校正 | **高通量结果必须报 FDR/BH**，不用 uncorrected P |
| 样本量 | 图/表必标 *n* = ? |
| 标准差/误 | SD 或 s.d. / SEM 或 s.e.m. |

## 4. 🔴 禁红绿（色盲）
**禁止用红/绿做语义编码**（正面绿/负面红）——色盲无法区分。
- ppt-master 引擎**实测会踩**（attention 样例第12页 O(1)绿/O(n)红）。
- 替代：用蓝/橙，或引擎本 deck 主色的深浅、加形状/标签区分。

## 5. 缩写首次展开
首次出现写全称(全称 + 缩写)，后续用缩写。常见缩写见 `glossary.md`。
