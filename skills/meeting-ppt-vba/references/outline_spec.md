# PPT大纲规范 (Outline Specification)

## JSON格式说明

PPT生成脚本接受JSON格式的大纲，包含以下结构：

```json
{
  "slides": [
    {
      "type": "slide_type",
      "title": "幻灯片标题",
      "notes": "演讲稿（可选）",
      ...其他属性
    }
  ]
}
```

## 通用字段

所有幻灯片类型都支持 `notes` 字段，用于添加演讲稿：

```json
{
  "type": "任意类型",
  "notes": "这里是演讲稿内容，将显示在PowerPoint的备注区域。\n\n可以使用换行符分段。建议每分钟约150字。"
}
```

### 讲稿编写要点

1. **时间匹配**：根据分配时长控制字数（约150字/分钟）
2. **结构清晰**：开头引入 → 中间展开 → 结尾过渡
3. **口语化**：避免书面语，使用自然的表达
4. **引人入胜**：善用设问、类比、故事等技巧

## 幻灯片类型

### 1. title (封面页)

```json
{
  "type": "title",
  "title": "演示标题",
  "subtitle": "副标题（可选）",
  "presenter": "汇报人",
  "date": "2026-01-16"
}
```

### 2. section (章节分隔页)

```json
{
  "type": "section",
  "number": 1,
  "title": "章节标题"
}
```

### 3. content (内容页)

```json
{
  "type": "content",
  "title": "幻灯片标题",
  "content": [
    "要点1",
    "要点2",
    "要点3"
  ]
}
```

### 4. two_column (双栏页)

```json
{
  "type": "two_column",
  "title": "幻灯片标题",
  "content": [
    "左侧要点1",
    "左侧要点2"
  ],
  "visual": "图表/图片说明"
}
```

### 5. table (数据表格页)

```json
{
  "type": "table",
  "title": "数据展示",
  "headers": ["列1", "列2", "列3"],
  "rows": [
    ["数据1", "数据2", "数据3"],
    ["数据4", "数据5", "数据6"]
  ]
}
```

### 6. conclusion (结论页)

```json
{
  "type": "conclusion",
  "title": "结论",
  "findings": [
    "主要发现1",
    "主要发现2",
    "主要发现3"
  ],
  "next_steps": [
    "下一步计划1",
    "下一步计划2"
  ]
}
```

### 7. thank_you (结束页)

```json
{
  "type": "thank_you",
  "email": "email@example.com"
}
```
